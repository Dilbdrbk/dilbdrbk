03 Approach

Four habits behind every project I lead.

How I approach SEO

  1. Start with the entity

    A project begins by defining the central entity and its attributes, so the whole site speaks about one subject with authority.

  2. Map the topic before writing

    Topical maps and content architecture come first. Briefs then pair entity-based optimization with search intent.

  3. Learn from the source

    Google's patents and whitepapers show which signals matter. I turn those findings into practical strategy.

  4. Test, then trust

    I run experiments on AI content, exact match domains and technical variables before a tactic goes into a live project.
