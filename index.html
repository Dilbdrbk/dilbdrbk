03 Approach

Four habits behind every project.

All ten habits

How I approach SEO

  1. Start with the entity

    A project begins by defining the central entity and its attributes, so the whole site speaks about one subject with authority.

  2. Map the topic before writing

    Topical maps and content architecture come first. Briefs then pair entity-based optimization with search intent.

  3. Learn from the source

    Search engine patents, research papers and official statements show which signals matter. I read official statements critically and check them against data.

  4. Test, then trust

    A/B tests separate SEO myths from facts. I validate an idea on test pages before it goes into a live project.
